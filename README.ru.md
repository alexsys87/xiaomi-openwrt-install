# Установка OpenWrt на Xiaomi AX3000T RD03v2 из Windows 10

[Original English documentation](README.md) · [Техническая документация (English)](docs/technical.md)

Пошаговая инструкция по установке через Wi-Fi, включая ошибки, встретившиеся
при реальной установке. Исходная английская инструкция сохранена.

## Проверено на реальном оборудовании

**11 октября 2026 года установка подтверждена на физическом роутере:**

| Параметр | Проверенная конфигурация |
|---|---|
| Компьютер | Windows 10, штатный PowerShell, Python 3.12 |
| Подключение | Wi-Fi, без WSL и Linux-утилит |
| Роутер | Xiaomi AX3000T **RD03v2** |
| Заводская прошивка | **2.0.28** |
| Устанавливаемый образ | **standard**, релиз **v1.14** |
| Результат | Постоянный OpenWrt в NAND; доступ к LuCI и смена пароля |

После установки отдельная проверка по Wi-Fi завершилась так:

```text
[3] ... ssh banner: SSH-2.0-dropbear
[3] installed board=xiaomi,mi-router-ax3000t-v2 rootfs_type=overlay
[+] OpenWrt is installed on NAND.
```

Это подтверждение конкретной установки, а не гарантия для всех версий Windows,
прошивок и аппаратных ревизий. Не переносите этот сценарий на другие модели.
Возврат на заводскую прошивку в рамках этой Windows-проверки не выполнялся.

## 1. Подготовка и безопасность

- Прочитайте [NOTICE](NOTICE). Используйте установщик только на своём роутере.
- Сохраните нужные заводские настройки: сброс удалит конфигурацию и пароли.
- Обеспечьте стабильное питание. Не отключайте питание при записи прошивки.
- Изолируйте подключение: к заводской и временной сети не должны подключаться
  посторонние устройства. Пароль временной сети общеизвестен.
- Установите Python 3.9 или новее с [python.org](https://www.python.org/downloads/windows/),
  включая launcher `py`.
- Скачайте ZIP репозитория и распакуйте либо клонируйте репозиторий. Откройте
  PowerShell в папке, содержащей `install.py`.

Установите зависимости **пока есть доступ к Интернету**:

```powershell
py -3 -m pip install -r requirements-windows.txt
py -3 install.py --list-interfaces
```

WSL, `sshpass`, `nmcli` и отдельная установка OpenSSL не нужны.
Не отключайте IPv6 на выбранном адаптере: поиск после перезагрузки использует
IPv6 link-local.

## 2. Образы и Интернет

Заводская Wi-Fi сеть Xiaomi может не предоставлять Интернет. Поэтому заранее
скачайте и проверьте образы нужного релиза для Wi-Fi, пока Интернет доступен:

```powershell
py -3 install.py standard --transport wifi --configure --release v1.14 --dry-run
```

`--dry-run` скачивает и проверяет образы без обращения к роутеру.
Здесь `v1.14` — **релиз, проверенный в этой установке**, а не обещание, что он
всегда будет последним. Без явного тега установщик выбирает последний релиз.
Сохраните локальный кэш и запускайте дальнейшие команды из той же папки.

Если образы уже были скачаны в предыдущем запуске и проверены по SHA-256,
повторная загрузка не нужна. Для автономного запуска необходимы явный тег
и полный комплект соответствующих образов в кэше.

## 3. Сброс и подключение к Xiaomi

1. Выполните аппаратный сброс кнопкой Reset согласно инструкции роутера.
2. Дождитесь загрузки и подключитесь к его заводской открытой Wi-Fi сети.
   В проверенном случае использовалось имя `minet_rd03_3b59`; у другого
   экземпляра имя может отличаться.
3. **Не завершайте мастер настройки Xiaomi** в браузере или Mi Home.
   Автоматически открывшуюся страницу можно закрыть.
4. Отключите VPN и конкурирующие подключения. Для установки по Wi-Fi
   отсоедините Ethernet. Не позволяйте Windows переключаться на домашнюю сеть.
5. Проверьте адаптер:

   ```powershell
   py -3 install.py --list-interfaces
   ```

У Wi-Fi адаптера обычно должен быть адрес `192.168.31.x`; заводской интерфейс
роутера доступен по `http://192.168.31.1`. Проверка страницы допустима,
прохождение мастера — нет. Сообщение Windows «Без доступа к Интернету» нормально.

В нашем случае нужный адаптер назывался `Беспроводная сеть` и имел индекс `12`.
**Ваш индекс может отличаться — подставляйте свой во все команды ниже.**

## 4. Запуск и постоянные пароли

С Интернетом:

```powershell
py -3 install.py standard --interface 12 --transport wifi --configure
```

С ранее скачанными образами проверенного релиза:

```powershell
py -3 install.py standard --interface 12 --transport wifi --configure --release v1.14 --offline
```

Вопросы установщика:

| Вопрос | Что вводить |
|---|---|
| `OpenWrt root password` | Новый пароль администратора OpenWrt. Рекомендуется не оставлять пустым. |
| `OpenWrt Wi-Fi SSID` | Имя постоянной сети, например `Xiaomi`. |
| `OpenWrt Wi-Fi password` | Новый пароль этой сети: 8–63 печатных ASCII-символа. |
| `Wi-Fi country code` | Двухбуквенный код фактической страны использования, например `RU` для России. |

Пароли при вводе не отображаются. Используйте для Wi-Fi латинские буквы, цифры
и обычные ASCII-знаки, без кириллицы, эмодзи и типографских кавычек. Сохраните
пароль безопасно. `BR` в подсказке — Бразилия, **не универсальное значение**.
В реальной установке было введено `BR`; после установки следует выбрать свою
страну. Постоянный пароль Wi-Fi не совпадает автоматически с паролем root.

## 5. Перезагрузки: три разные Wi-Fi сети

Не закрывайте PowerShell и не запускайте вторую копию установщика.
Следуйте запросам подтверждения перед необратимыми операциями.

1. **Заводская сеть Xiaomi.** После начальной настройки установщик перезагружает
   роутер и выводит `waiting up to 300s for tcp/19553`. Это нормальное ожидание
   запуска службы, а не сообщение об ошибке. Если Windows отключилась,
   подключитесь обратно к заводской сети. Пока не ищите временный OpenWrt.
2. **Временная RAM-система.** После перехода в неё вручную подключитесь к:

   ```text
   SSID: OpenWrt-RD03v2-Installer
   Пароль: rd03v2install
   ```

   Эти параметры были напечатаны в проверенном запуске. Если ваша версия
   выводит другие, используйте параметры из её вывода.
3. **Постоянный OpenWrt.** После записи и перезагрузки временная сеть исчезнет.
   Подключитесь к SSID, заданному при `--configure`, с вашим новым паролем.
   Установщик ждёт постоянную систему на выбранном интерфейсе до 600 секунд.

При сообщениях `flash-started` и `do not touch the power` **не отключайте
питание, не сбрасывайте роутер и не повторяйте стадию прошивки**.

## 6. Разбор ошибок из реальной установки

### Кириллица в имени интерфейса и `Interface ... not found`

В PowerShell имя при копировании может искажаться. Используйте числовой индекс
из `--list-interfaces`, например `--interface 12`, а не текстовое имя.
Индекс после изменений адаптеров может поменяться.

### `--interface Ethernet does not match the kernel route ... via Беспроводная сеть`

Windows направляет трафик к роутеру через другой адаптер. `--interface` не
исправляет системную маршрутизацию: установщик останавливается до использования
одноразового триггера. Подключитесь к нужному роутеру, отключите VPN и
конкурирующую сеть, проверьте адрес и повторно выберите правильный интерфейс.
Адрес Wi-Fi `192.168.3.38` в нашем случае не соответствовал ожидаемой заводской
подсети Xiaomi `192.168.31.x`.

### `V2 CAP path is unavailable (netmode=4)` и `inited=1`

В проверенном случае роутер уже был настроен. Выполните заводской сброс,
подключитесь к заводской сети и **не проходите мастер Xiaomi**.
После сброса следующий запуск обнаружил `inited=0` и продолжил установку.
Если ошибка повторяется после корректного сброса, сохраните лог и выясните
причину; не пытайтесь принудительно обходить проверки.

### GitHub: `The handshake operation timed out`

Не удалось получить сведения о релизе по HTTPS. Это не означает неисправность
роутера: на заводском Wi-Fi может не быть Интернета. Если комплект `v1.14`
уже скачан, используйте команду с `--release v1.14 --offline` из раздела 4.
Если кэш неполный, сначала скачайте образы с Интернетом. Один `--offline`
не заменяет загрузку. Из-за этой ошибки повторный сброс не нужен.

### `WPA2 passphrase must contain printable ASCII characters`

Пароль содержит недопустимые символы. Переключите раскладку на английскую
и задайте пароль из печатных ASCII-символов.

### `WPA2 passphrase must be 8-63 printable ASCII characters`

Проверьте длину: от 8 до 63 символов. Эти ошибки проверки конфигурации возникали
до начала записи прошивки.

### Обратное подключение не приходит: брандмауэр

Сначала проверьте сеть и маршрутизацию. Если блокируется входящее подключение,
разрешите выбранный `python.exe` и необходимые порты только от заводского роутера.
В PowerShell **от имени администратора**:

```powershell
$python = py -3 -c "import sys; print(sys.executable)"
New-NetFirewallRule -DisplayName "Xiaomi OpenWrt installer" -Direction Inbound -Action Allow -Program $python -Protocol TCP -LocalPort 8000,4444,4445 -RemoteAddress 192.168.31.1 -Profile Any
```

Это правило для стандартного адреса и портов; при их изменении скорректируйте
правило. Не отключайте брандмауэр целиком. После завершения удалите исключение:

```powershell
Get-NetFirewallRule -DisplayName "Xiaomi OpenWrt installer" | Remove-NetFirewallRule
```

### Прошивка запущена, но `permanent OpenWrt was not verified`

Сообщение `sysupgrade was launched; do not run the flash stage again` означает,
что повторять запись нельзя. Отсутствие обнаружения на Wi-Fi само по себе
не доказывает неудачу установки. Подключитесь к постоянной сети и выполните
**только проверку**, используя `resume.json` именно этого запуска:

```powershell
py -3 install.py --verify-only ".\install-20261011-231648\resume.json" --verify-interface 12
```

Имя папки выше — из реального запуска; замените его на путь, напечатанный вашим
установщиком. Не используйте манифест другого роутера или другой установки.
Можно проверять по LAN-кабелю, указав индекс Ethernet (в нашем списке — `18`):

```powershell
py -3 install.py --list-interfaces
py -3 install.py --verify-only ".\install-20261011-231648\resume.json" --verify-interface 18
```

При изменённом пароле root следуйте запросам/диагностике установщика; не
возвращайте пустой пароль ради проверки. Именно повторная проверка по Wi-Fi
в этой установке обнаружила Dropbear, правильную плату и постоянный overlay,
после чего вывела `OpenWrt is installed on NAND.`

### Забыт постоянный пароль Wi-Fi

Если установка ещё идёт, пароль временной сети — `rd03v2install`.
Не прерывайте запись и не меняйте параметры посреди неё.

После загрузки постоянного OpenWrt подключитесь к **LAN-порту** кабелем,
получите адрес автоматически и откройте `http://192.168.1.1` (типовой адрес
OpenWrt, если вы его не меняли). В LuCI войдите с установленным паролем root;
если он действительно оставлен пустым и ещё не изменён, возможен вход без него.
В **Network → Wireless → Edit → Wireless Security** задайте новый пароль,
затем **Save & Apply**. Заводской сброс для этого не нужен.

## 7. После успешной установки

- Когда проверка подтвердила NAND, PowerShell можно закрыть.
- Если в логе было `root password=unset`, задайте пароль администратора:
  **System → Administration**. Не оставляйте роутер без пароля.
- Проверьте страну и безопасность Wi-Fi; выберите фактический регион.
- Сохраните резервную копию настроек:
  **System → Backup / Flash Firmware → Generate archive**.
- Храните папку установки, резервные копии, `firstboot.tar.gz` и `resume.json`
  в закрытой папке. Они могут содержать пароли, сеансовые секреты и данные
  конкретного устройства. Не публикуйте их или полные логи без очистки секретов.
- Для восстановления и возврата к заводской системе используйте
  [английскую инструкцию](README.md#return-to-stock) и
  [технический справочник](docs/technical.md), а не повторный запуск прошивки
  после `flash-started`.
